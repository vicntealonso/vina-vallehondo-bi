# Entrega 2

Aquí va el informe final de la Entrega 2 (Word y PDF) cuando se entregue.

El borrador se genera desde el repositorio con:

```bash
python run.py
python entrega2/build_informe_e2.py entrega2/captura_prototipo_e2.png
```

Eso deja `informe/Entrega 2.docx` (local, no se sube). La versión final revisada se copia a esta carpeta.
